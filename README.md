# The Capitol Theatre: test website

Test version of the new website for The Capitol Theatre, owned and operated by Portal Players Dramatic Society, Port Alberni, BC.

- Plain HTML and CSS: no WordPress, no database, no build step.
- Published with GitHub Pages for board review.
- Every page tells search engines not to index it (`noindex` and `robots.txt`). Remove these before going live on atthecapitol.org.

Pages: home, What's On, 7 show pages, Season Pass, Tickets, Portal Players, Membership, Board & Governance, Our History, Helen Ford, Get Involved, Rentals, Visit & Contact.
